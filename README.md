# ClaimKeeper: demo

A customer-side tracker for refund and warranty claims. Log the claim and every contact attempt. It flags when a company has gone silent, suggests the next step (follow up, escalate, or the typical card-dispute window), and writes a dated escalation letter (US/UK/EU wording).

It is static HTML/JS with localStorage only, no APIs or keys. The sample claim is illustrative. This is general information, not legal advice.

To publish: Settings → Pages → Deploy from branch → main / root.
